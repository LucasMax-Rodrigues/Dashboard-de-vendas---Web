## ✨ Sobre o Projeto

Este é o meu **primeiro contato com desenvolvimento web**, desenvolvido do zero utilizando apenas **HTML, CSS e JavaScript puro** — sem frameworks, sem bibliotecas externas.

O projeto nasceu da vontade de aprender na prática, e o resultado foi um dashboard moderno com tema escuro, métricas automáticas e interatividade completa.

---

## 🖥️ Funcionalidades

- ✅ **Cadastro de produtos** com nome e preço
- 📈 **Cálculo automático** da média de preços
- 🔴 **Destaque do produto mais caro**
- 🟢 **Destaque do produto mais barato**
- 🗑️ **Marcar produto como vendido** (remove do estoque)
- 🔊 **Feedback sonoro** ao cadastrar e ao vender
- 📱 **Layout responsivo** para mobile e desktop

---

## 🎨 Visual

O dashboard foi construído com um **tema escuro moderno**, utilizando:

- Paleta de cores em tons de azul e cinza escuro
- Cards com efeito hover
- Header com imagem de fundo e overlay
- Tabela estilizada com scroll horizontal em telas menores
